# pfa-ecg
# 🫀 ECG Classification Web Application

A Machine Learning-based web application for automated ECG signal classification.

---

## 🚀 Live Demo
🔗 https://ileeeef-pfa-ecg.hf.space/

---

## 📌 Project Overview
This project presents an intelligent system capable of analyzing ECG signals and classifying them using a trained machine learning model(Random Forest).

The system includes:
- ECG signal preprocessing
- Feature extraction
- Model prediction
- Interactive web interface
